## How to run locally

No build step, no dependencies. Just open the file:

```
index.html  →  double-click or open in any browser
```

Or serve it with any static file server, for example:

```bash
# Python (built-in)
python -m http.server 8080

# Node (npx)
npx serve .
```

Then visit `http://localhost:8080` in your browser.

## Curiosity Terminal commands

| Command      | What it does                                |
|-------------|---------------------------------------------|
| `help`       | Lists all available commands                |
| `superpower` | What drives my approach to technology       |
| `skills`     | Technical areas and tools                   |
| `projects`   | Current and completed projects              |
| `funfact`    | Something you wouldn't expect               |
| `surprise`   | Rotating reveal — run it multiple times     |
| `clear`      | Resets terminal output                      |

- Click any command chip, or type in the input and press Enter
- Use ↑ / ↓ arrow keys to navigate command history
- Press Tab to autocomplete a partial command
- Press Escape to blur the terminal input (so keyboard navigation works normally)

## Features

- Dark charcoal + deep forest-green colour palette with lime accents
- `JetBrains Mono` + `Inter` typography
- Fully responsive: desktop, tablet, mobile
- Semantic HTML with ARIA labels and roles
- Keyboard-accessible navigation and terminal
- Skip-to-content link for screen readers
- `prefers-reduced-motion` respected
- Scroll reveal animations (IntersectionObserver)
- Active nav link highlighting on scroll
- No frameworks, no dependencies, no build step
