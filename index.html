About Me

Third-year AI & ML engineering student at Siddhant College of Engineering, Pune — building things with software, hardware, and a lot of curiosity.

I gravitate toward the edges where disciplines overlap: robotics that needs design thinking, mobile apps that need ML intuition, UI concepts that need engineering clarity. When I pick up a new tool or framework, it's usually because a project demanded it — not because it was trending.

I enjoy going beyond the conventional classroom experience (well, I didn't go beyond… iykyk lol). The honest version is: I learn best when there's something real to build or break.

Currently interested in the intersection of AI, accessible software design, and the quiet philosophy of why technology exists in the first place.

What I'm working on: Multi-role authentication flows, ML-based image classification pipeline, and real-time Firestore sync between citizens and workers.

What I Learned

01

Responsive Web Development

Building a layout that holds up across screen sizes without a framework forces you to understand CSS more deeply than any tutorial does.

02

JavaScript Interactions

Writing the Curiosity Terminal in vanilla JS — state, history, command parsing — was a useful reminder that the platform is powerful on its own.

03

GitHub Workflow

Version control for a single-person project still matters. Commit messages read back like a build log — useful when something breaks at 2am.

04

AWS Amplify Deployment

Connecting a GitHub repository to Amplify and watching a static site go live is a satisfying loop — push a change, see it deployed.

05

Design as Communication

Visual design isn't decoration — it's how a site communicates before a word is read. Every spacing decision, colour choice, and type scale is an argument.

06

Personal Identity, Digitised

Writing about yourself for a portfolio is harder than writing code. Figuring out what to include, what to leave out, and what tone to use is a design problem.
